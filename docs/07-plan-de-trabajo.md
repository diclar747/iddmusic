# Plan de trabajo para el programador
## Sprint 1 — Base y seguridad
- Revisar estructura y corregir inconsistencias.
- Migraciones versionadas.
- Invitaciones, activación, gestión de roles y pruebas de auth.
## Sprint 2 — Biblioteca musical
- CRUD completo, filtros, búsqueda full-text, categorías.
- Editor estructurado de letras y acordes.
- Tests de transposición.
## Sprint 3 — Documentos
- Upload seguro, visor PDF, imágenes, vínculo canción-archivo.
- OCR y pipeline OMR como tareas asíncronas.
## Sprint 4 — Colaboración
- Grupos, membresías, permisos, canciones compartidas.
- Repertorios con orden, tonalidad y responsables.
## Sprint 5 — PWA
- Instalación, caché de shell, IndexedDB, descargas offline y sincronización.
## Sprint 6 — Producción
- Pruebas, hardening, backups, monitoreo, HTTPS, documentación y capacitación.
